## 🚀 Projets
Voici quelques projets que j’ai réalisés :

  Application mobile complète avec logique de jeu, interface tactile et gestion des règles.

- 🚢 **Battleship (Web)**  
  Jeu de bataille navale jouable dans le navigateur avec interface interactive et logique de partie.
